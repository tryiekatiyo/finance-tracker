💰 Finance Tracker

📌 About the Project

Finance Tracker is a project developed to help users monitor and manage their financial activities. It focuses on making it easier to keep track of income, expenses and personal finances.

🎯 Project Objectives

* To help users monitor their financial activities.
* To provide a simple way of recording income and expenses.
* To encourage better financial management.

🛠️ Technologies Used

* Python – Main programming language.
* Django – Web application framework.
* SQLite – Database management.
* HTML – Structure of the web pages.
* CSS – Styling and layout.
* Chart.js – Data visualisation and charts.
